# 通用检查清单（语言无关）

评审时逐项过一遍。不是每项都要报，命中才写。

## 正确性

- 条件判断有没有取反、漏掉 else、多个分支是否互斥且完整
- 循环边界：`<` 还是 `<=`，空集合、单元素、首尾元素
- 状态机：是否存在非法状态迁移；重试、取消、超时后状态有没有复位
- 返回值：失败路径是否返回了错误值，还是返回了默认值假装成功
- 数值：整数溢出、浮点精度、单位（秒/毫秒、元/分）、货币精度
- 时间：时区、夏令时、跨天、服务器与本地时间不一致
- 排序/分页：稳定排序、重复数据、最后一页、总数变化
- 幂等：重复点击、重复请求、重试会不会产生重复数据

## 空值与边界

- nil / null / undefined / 空字符串 / 空数组 / 空对象
- 0、负数、超大数据、超长字符串、特殊字符、emoji
- 字段缺失（老版本接口）、多返回一个字段
- 首次启动、无网络、弱网、超时、服务器 5xx

## 错误处理

- 每个可能失败的操作是否都有处理：网络、解析、文件、数据库、权限
- 有没有 `try?` / `catch {}` / `except: pass` 这类吞异常写法
- 错误是否被转换成了用户能理解的提示，而不是直接抛原始错误
- 失败后是否有重试或降级；重试有没有上限和退避
- 部分成功（批量操作）怎么处理

## 并发与生命周期

- 共享可变状态是否加锁 / 串行队列 / actor
- 回调、闭包、监听器是否造成循环引用或泄漏
- 异步任务是否可取消；页面销毁后回调还会不会执行
- 线程模型：UI 是否在主线程；数据库是否在正确队列
- 顺序依赖：并发执行会不会导致结果不确定

## 性能

- 主线程上的 IO、解析、大量计算、图片解码
- 循环内的重复计算、重复查库、N+1 查询
- 列表是否复用；大图是否降采样
- 内存是否持续增长（缓存无上限、监听未移除）
- 启动路径上的同步初始化

## 可维护性

- 命名是否表达意图；缩写是否可理解
- 重复代码超过 3 处是否该抽公共方法
- 魔法数字 / 魔法字符串是否该常量化
- 函数是否过长（超过 50 行要警惕）、嵌套是否过深
- 注释是否解释「为什么」，而不是复述「做了什么」
- 死代码、调试日志、临时开关是否清理

## 兼容性

- 老版本系统 / 老版本 App / 老接口
- 多语言、RTL、长文案、深色模式、大字体
- 不同屏幕尺寸、折叠屏、分屏
- 权限未授予、权限被拒绝、权限被回收
- 灰度 / 开关关闭时的行为
