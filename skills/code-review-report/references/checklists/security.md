# 安全专项检查清单

涉及登录、支付、密钥、文件上传、权限、外部输入时，必须过这一份。

## 凭据与敏感信息

- 代码、配置文件、注释里是否有明文密钥、token、密码、证书私钥
- 密钥是否被提交进 Git 历史（提交后即视为泄露，需轮换）
- 日志、崩溃上报、埋点是否包含手机号、身份证、车架号、地址、token
- 错误提示是否泄露内部实现（堆栈、SQL、服务器路径）
- 测试环境与生产环境是否共用凭据

## 认证与授权

- 接口是否做了身份校验，而不只是前端隐藏入口
- 越权：能否通过修改 ID 访问他人数据（水平越权）、普通用户能否调管理接口（垂直越权）
- token 存储位置（Keychain / HttpOnly Cookie / localStorage）
- token 过期、刷新、注销后是否立即失效
- 敏感操作是否二次校验（改密码、支付、解绑车辆）

## 输入与输出

- 所有外部输入是否校验：类型、长度、范围、格式、枚举
- SQL / 命令 / 路径拼接是否参数化；路径穿越 `../`
- 前端渲染是否转义；富文本是否过滤
- 文件上传：类型、大小、内容校验、存储路径、可执行性
- 反序列化不可信数据（`pickle`、`eval`、Java 反序列化）

## 传输与存储

- 是否强制 HTTPS；是否关闭了 ATS / 证书校验
- 证书固定（pinning）是否可被绕过（仅作参考，不当阻断项）
- 本地敏感数据是否加密（Keychain / Keystore）
- 备份、截图、剪贴板是否泄露敏感信息

## 依赖与配置

- 新增第三方依赖的来源与维护状态
- 调试开关、测试后门、Mock 账号是否带入生产
- 权限申请是否最小化（定位、通讯录、相册）
- WebView 是否允许任意 URL、是否开启 JS 桥接且未校验来源
