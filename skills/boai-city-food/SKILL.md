# 城市美食雷达 — boai-city-food

一句话进来，直接开干：**零提问**。从用户原话提取城市名 → 全网调研 → 星级定档 → 按区整理 → PDF + 聊天精华。

核心原则：**星级就是口碑**——每颗星都要有多来源支撑，宁缺毋滥；每条推荐都要能照着走（店名/地址/招牌菜价格/人均）。

## 阶段 1：城市识别（零提问）

- 从一句话提取城市名；处理别名与简称：羊城/花城=广州、蓉城=成都、山城=重庆、鹏城=深圳、星城=长沙、春城=昆明、冰城=哈尔滨
- 歧义时按上下文取最知名者，不追问（如「鼓楼区」→ 默认南京）
- **默认口径**：按当地特色 + 大众口味；只有用户主动说「吃不了辣」「预算 X 元」才调整
- 覆盖范围：全球城市均可，国内城市优先（点评/必吃榜/非遗数据质量高）；境外城市用米其林/必比登 + 本地媒体 + 游客口碑

## 阶段 2：全网调研（WebSearch，并行）

按城市层级选权威源，**每条关键事实记录来源 URL**：

| 搜索方向 | 查询示例 | 适用 |
|---------|---------|------|
| 城市招牌菜 | 「城市名 必吃 美食 代表」 | 全部 |
| 权威榜单 | 「城市名 米其林 必比登」「城市名 黑珍珠」「城市名 必吃榜」 | 一线/新一线 |
| 官方认证 | 「城市名 非遗美食」「城市名 中华老字号 美食」「地理标志」 | 全部 |
| 菜系覆盖 | 「城市名 粤菜/川菜/湘菜/潮汕/客家/甜品 老店」逐菜系搜 | 全部 |
| 全域覆盖 | 每个行政区都搜，**远郊不能漏**（广州花都/从化/增城/番禺级），远郊以农庄/镇街老店为主，每区 3-5 家 4★ 起步；郊区分区成章（番禺/增城/黄埔…各一节），并搜「区名+美食+探店/博主」挖掘 B站/头条等博主渠道的宝藏店；美食大区（番禺级）还要搜官方「美食地图/十大名菜名点」并收录；**跨菜系章的名店要在所属区一节重复收录并注「详见X章」**，避免用户按区找店时漏看 | 全部 |
| 本地口碑 | 「本地人 私藏 30年老店」「街坊 口碑 避开网红店」「XX区 街坊饭堂」 | 全部 |

**调研铁律**（沿用美食推荐权重体系）：
- 🚨 价格、榜单、排队规律是最易过时的信息——必须检索，检索不到写「以门店为准」，**绝不编造**
- 🚨 「本地人最爱」需多来源反复提及，博主单次推荐不能冒充本地口碑
- 🚨 **五档分层收录，一档都不能少**：①名店老字号（陶陶居/广州酒家级）②高端食府（利苑/白天鹅级）③海鲜河鲜（黄沙市场/东江级）④连锁品质（点都德级）⑤街坊老店（惠食佳/吴财记级）——游客视角与本地视角互补，不排他、不偏科
- 🚨 **高端档必须主动检索**：搜「城市名 米其林 星级 名单 当前年份」，完整榜单中的二星/一星代表要列全（或至少列前 5），高端档不少于 5 家——不能等用户点名才发现漏了利苑
- 🚨 **必比登完整名单要全列**：已收录各章的注「散见」，未收录的补入「必比登速览」表（注意区分城市：广深合并发布时别把深圳的名单算给广州）
- 🚨 **大众点评必吃榜**：搜官方榜单（数量+分区分布）并收录；每区实时前三在点评 App 内动态更新，公开检索拿不到准确名次——注明「App 内查看」，**绝不编造名次**
- 🚨 **特色品类必须覆盖**：城市小众特色品类（广州牛三星/牛杂/咸煎饼/猪杂粥级）要单列或带代表，不能只写大类（早茶/粤菜/川湘这种）；**火锅打边炉、烤肉烧烤必须作为独立品类覆盖**，不要漏
- 权威标签有什么挂什么，不硬凑（小城市没有米其林就不挂）
- 记录完整 URL 用于文末 Sources

## 阶段 3：星级定档与分区整理

### 星级体系

| 星级 | 含义 | 每城市数量 |
|------|------|-----------|
| ★★★★★ | **必吃**：城市招牌，不吃等于没来（如广州早茶、长沙臭豆腐级） | 3-5 个 |
| ★★★★☆ | **推荐**：值得专程/区域代表，本地人认可 | 不限 |
| 4★ 以下 | **一律不收录**——只推荐值得专门去的，宁缺毋滥 | — |

### 每条推荐必须包含的 5 项结构化信息

1. **店名 + 地址**——商圈/街道级 + 导航关键词（门牌号易过时）
2. **招牌菜名 + 价格**——单品价格；查不到写「以门店为准」
3. **人均消费**——检索或按招牌菜推算（标注约）
4. **权威标签**——米其林/黑珍珠/必吃榜/非遗/老字号/本地人最爱，不硬凑
5. **排队贴士**——营业时间、建议到店时间、售罄规律

### 菜系分章规则（主线）

- **按菜系分章**，不是按区：粤菜 / 潮汕菜 / 客家菜 / 川菜 / 湘菜 / 糖水甜品 / 粥粉面小吃…按城市实际菜系结构取舍（如广州：粤式早茶名店 / 粤菜正餐与高端食府 / 海鲜河鲜 / 粥粉面与特色小吃 / 牛三星牛杂等本地隐藏特色单列 / 炖品糖水 / 潮汕·客家 / 川湘）。章节标题用「老广私藏」「隐藏菜单」这类自然说法，**不要用「背地」等易误读的词**
- 每家店必须带**菜系徽章**（粤菜/潮汕/客家/川菜/湘菜/甜品/小吃）+ **档位徽章**（名店/高端/海鲜/连锁/街坊），一眼可辨
- 城市级招牌菜（如广州早茶）放总榜，具体店分到对应菜系章
- 某菜系搜不到过硬老店 → 只写有把握的，宁缺毋滥，并注明「该菜系本地硬店信息有限」
- **文末必附「分区速查」表**：区 → 代表店 2-5 家（跨引用各菜系章），所有行政区含远郊一表看清
- 非遗特色品类（凉茶/沙河粉/地方性小吃）也要有代表，不能只写菜

## 阶段 4：PDF 交付

1. 读取本 skill 目录 `assets/food_template.html`，按注释槽位填充（保留全部 CSS）
2. 结构固定：**封面 / ①美食总榜 / ②分区详解 / ③实用贴士+Sources**
3. 封面：城市名 + 美食宣传语（检索「城市 美食 口号」或自拟贴切的）+ 数字条（N 道必吃 / N 家推荐 / N 个区）+ `Designed by boai`；背景图用城市代表美食/地标图（Wikimedia Commons，走 Clash 代理 `-x http://127.0.0.1:7890` + User-Agent 头，base64 内嵌，来源写进 Sources；拿不到就删掉 img 与 grad 行）
4. 用 `scripts/html2pdf.sh` 转 PDF → `~/Documents/美食攻略/{城市}美食推荐.pdf`
5. 校验：文件非空、页数合理（6-15 页）

## 阶段 5：聊天回复

1. 总榜精华表：TOP 5-10（星级/店名·地址/招牌菜价格/人均）
2. 每区一句话速览
3. ⚠️ 关键贴士（排队/售罄/辣度）
4. PDF 路径
5. **Sources：** 用到的 URL 以 markdown 链接列出（WebSearch 硬性要求）

## 质量红线

- ❌ 编造价格、榜单、人均——查不到标「以门店为准」
- ❌ 凭训练记忆写具体数字
- ❌ 只有店名没有地址/价格/人均
- ❌ 把博主单次推荐写成「本地人最爱」
- ❌ 星级无来源支撑，或 5★ 泛滥
- ❌ 文末没有 Sources 链接
- ❌ 用户有明确称呼偏好时不遵守（参考会话记忆）

## 交付检查清单

```
□ 城市识别正确（含别名），零提问
□ 按菜系分章，每家店带菜系徽章；各菜系都检索过，来源 URL 齐全
□ 五档分层收录（名店/高端/海鲜/连锁/街坊）一档不缺；特色小众品类有代表
□ 全域覆盖：含远郊每区至少 1 家 4★ 代表；4★ 以下一律不收录
□ 星级符合体系（5★ 3-5 个，4★ 每菜系 1-3 个）
□ 每条推荐带 店名/地址/招牌菜价格/人均/标签/贴士
□ 「本地人最爱」多来源交叉验证，游客店不挂本地标签
□ 封面含城市名+宣传语+数字条+Designed by boai
□ PDF 生成到 ~/Documents/美食攻略/ 且页数合理
□ 聊天含总榜+菜系速览+贴士+Sources
□ 称呼符合用户偏好
```

## 案例参考（质量水位）

《广州美食推荐》：总榜 5 个 5★（惠食佳啫啫煲、万年酒楼至尊烧鹅皇、海门鱼仔店潮汕菜、荣华楼早茶、吴财记云吞面——全部为街坊老店/米其林/必吃榜交叉背书），按菜系分六章（粤菜正餐老店 / 粤式早茶 / 粥粉面小吃 / 糖水甜品 / 潮汕·客家 / 川菜·湘菜），每家带菜系徽章+招牌菜价格+人均；连锁品牌仅点都德一家且标「备选」，游客店不挂本地标签。PDF 封面数字条「5 道必吃 / 32 家推荐 / 8 大菜系」。
