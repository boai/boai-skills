# 城市美食雷达 — boai-city-food

一句话进来，直接开干：**零提问**。从用户原话提取城市名 → 全网调研 → 星级定档 → 按区整理 → PDF + 聊天精华。

核心原则：**星级就是口碑**——每颗星都要有多来源支撑，宁缺毋滥；每条推荐都要能照着走（店名/地址/招牌菜价格/人均）。

## 阶段 1：城市识别（零提问）

- 从一句话提取城市名；处理别名与简称：羊城/花城=广州、蓉城=成都、山城=重庆、鹏城=深圳、星城=长沙、春城=昆明、冰城=哈尔滨
- 歧义时按上下文取最知名者，不追问（如「鼓楼区」→ 默认南京）
- **默认口径**：按当地特色 + 大众口味；只有用户主动说「吃不了辣」「预算 X 元」才调整
- 覆盖范围：全球城市均可，国内城市优先（点评/必吃榜/非遗数据质量高）；境外城市用米其林/必比登 + 本地媒体 + 游客口碑

## 阶段 2：全网调研（WebSearch，并行）

按城市层级选权威源，**每条关键事实记录来源 URL**：

| 搜索方向 | 查询示例 | 适用 |
|---------|---------|------|
| 城市招牌菜 | 「城市名 必吃 美食 代表」 | 全部 |
| 权威榜单 | 「城市名 米其林 必比登」「城市名 黑珍珠」「城市名 必吃榜」 | 一线/新一线 |
| 官方认证 | 「城市名 非遗美食」「城市名 中华老字号 美食」「地理标志」 | 全部 |
| 分区深挖 | 「城市名 XX区 美食 老店 本地人」 | 每个区 |
| 本地口碑 | 「本地人 推荐 哪家正宗 排队」 | 全部 |

**调研铁律**（沿用美食推荐权重体系）：
- 🚨 价格、榜单、排队规律是最易过时的信息——必须检索，检索不到写「以门店为准」，**绝不编造**
- 🚨 「本地人最爱」需多来源反复提及，博主单次推荐不能冒充本地口碑
- 权威标签有什么挂什么，不硬凑（小城市没有米其林就不挂）
- 记录完整 URL 用于文末 Sources

## 阶段 3：星级定档与分区整理

### 星级体系

| 星级 | 含义 | 每城市数量 |
|------|------|-----------|
| ★★★★★ | **必吃**：城市招牌，不吃等于没来（如广州早茶、长沙臭豆腐级） | 3-5 个 |
| ★★★★☆ | **值得专程**：区域头牌，本地人排队店 | 每区 1-3 个 |
| ★★★☆ | **顺路可吃**：路过该区值得安排 | 不限 |
| 3★ 以下 | 不收录（好评推荐制，只写值得吃的） | — |

### 每条推荐必须包含的 5 项结构化信息

1. **店名 + 地址**——商圈/街道级 + 导航关键词（门牌号易过时）
2. **招牌菜名 + 价格**——单品价格；查不到写「以门店为准」
3. **人均消费**——检索或按招牌菜推算（标注约）
4. **权威标签**——米其林/黑珍珠/必吃榜/非遗/老字号/本地人最爱，不硬凑
5. **排队贴士**——营业时间、建议到店时间、售罄规律

### 分区规则

- 国内城市按**行政区**（越秀/天河/荔湾…）；境外按城区/核心商圈
- 每区一章：区名 + 一句该区美食气质 + TOP 3-5 家
- 城市级招牌菜（如广州早茶）放在总榜，具体店分到区里

## 阶段 4：PDF 交付

1. 读取本 skill 目录 `assets/food_template.html`，按注释槽位填充（保留全部 CSS）
2. 结构固定：**封面 / ①美食总榜 / ②分区详解 / ③实用贴士+Sources**
3. 封面：城市名 + 美食宣传语（检索「城市 美食 口号」或自拟贴切的）+ 数字条（N 道必吃 / N 家推荐 / N 个区）+ `Designed by boai`；背景图用城市代表美食/地标图（Wikimedia Commons，走 Clash 代理 `-x http://127.0.0.1:7890` + User-Agent 头，base64 内嵌，来源写进 Sources；拿不到就删掉 img 与 grad 行）
4. 用 `scripts/html2pdf.sh` 转 PDF → `~/Documents/美食攻略/{城市}美食推荐.pdf`
5. 校验：文件非空、页数合理（6-15 页）

## 阶段 5：聊天回复

1. 总榜精华表：TOP 5-10（星级/店名·地址/招牌菜价格/人均）
2. 每区一句话速览
3. ⚠️ 关键贴士（排队/售罄/辣度）
4. PDF 路径
5. **Sources：** 用到的 URL 以 markdown 链接列出（WebSearch 硬性要求）

## 质量红线

- ❌ 编造价格、榜单、人均——查不到标「以门店为准」
- ❌ 凭训练记忆写具体数字
- ❌ 只有店名没有地址/价格/人均
- ❌ 把博主单次推荐写成「本地人最爱」
- ❌ 星级无来源支撑，或 5★ 泛滥
- ❌ 文末没有 Sources 链接
- ❌ 用户有明确称呼偏好时不遵守（参考会话记忆）

## 案例参考（质量水位）
